# Curriculo B1 en 80 lecciones

Este documento fija el alcance curricular de Paruski hasta B1. No describe la
implementacion tecnica; describe que debe cubrir cada leccion.

## Principios

- 80 lecciones secuenciales.
- Tramos:
  - 1-20: A0-A1 inicial.
  - 21-40: A1 consolidado.
  - 41-60: A2 operativo.
  - 61-80: transicion a B1.
- Cada leccion debe introducir alrededor de 100 lemas utiles o reciclables.
- Cada leccion debe introducir 5-10 estructuras nuevas.
- Cada leccion debe tener tres capas de practica:
  - vocabulario puro;
  - gramatica pura;
  - mixto, con lexico y gramatica combinados.

## Objetivo B1 al cierre de la leccion 80

El alumno debe poder:

- sostener interacciones cotidianas y academicas simples;
- describir personas, lugares, rutinas, planes y problemas;
- narrar hechos pasados y planes futuros;
- manejar oposiciones clave de caso, movimiento y aspecto;
- entender conversaciones reales lentas o medias con redundancia natural;
- producir frases y parrafos breves con control suficiente para no depender de plantillas.
